# SENSOR CONTROL UNIT (SCU-3) — User Manual

คู่มือการใช้งานโปรแกรม **SCU-3** สำหรับตั้งค่า Sensor Limit + Timing และดูสถานะการทำงานแบบ real-time ผ่าน Serial

> เวอร์ชันปัจจุบัน: **v1.3.0 (v3)**

---

## 🔷 1. Overview

SCU-3 เป็นโปรแกรมสำหรับ:

* เชื่อมต่อกับตัวเครื่องผ่าน USB (Serial 9600 baud)
* อ่านค่า limit และค่าเวลา (timing) ปัจจุบันจากบอร์ดอัตโนมัติ
* ปรับตั้งค่า Sensor **3 ช่อง** (CH01 / CH02 / CH03)
* ตั้งค่าเวลา **TURN ON / TURN OFF** ของ Relay
* แสดงค่าระยะ sensor (S1/S2/S3) และสถานะ Relay (ON/OFF) แบบ real-time
* ส่งค่ากลับไปยังอุปกรณ์ด้วยปุ่ม **WRITE CONFIGURATION**

## 🔷 3. การเชื่อมต่ออุปกรณ์

### ขั้นตอน

1. เสียบตัวเครื่องเข้าคอม
2. เปิดโปรแกรม SCU-3
3. โปรแกรมจะ **SCAN พอร์ตอัตโนมัติ** ตอนเปิด และเลือก COM port แรกให้
4. หากต้องการเปลี่ยน ให้เลือก COM port จาก dropdown ในส่วน **00 · COMMUNICATION**
5. โปรแกรมจะ **connect อัตโนมัติ** ทันทีที่เลือกพอร์ต

## 🔷 4. สถานะระบบ

| สถานะ                  | ความหมาย          |
| ---------------------- | ------------------ |
| CONNECTED (จุดเขียว)   | เชื่อมต่อสำเร็จ    |
| OFFLINE (จุดแดงกระพริบ) | ยังไม่เชื่อมต่อ    |
| CONNECTING…            | กำลังเชื่อมต่อ     |
| CONNECTION FAILED      | เชื่อมต่อไม่สำเร็จ |

* แถบสถานะด้านล่างสุดจะแสดง เช่น `CONNECTED · COM7 · 9600 BAUD`
* Pill มุมขวาบนของส่วน COMMUNICATION แสดงชื่อพอร์ต/OFFLINE

## 🔷 5. การอ่านค่าอัตโนมัติ (Auto Sync)

หลังจาก connect สำเร็จ โปรแกรมจะดึงค่าจากบอร์ดให้ทันที:

* **Limit** ของ CH01 / CH02 / CH03 (คำสั่ง `GET` → `LIMIT:`)
* **Timing** TURN ON / TURN OFF (คำสั่ง `GETTIME` → `TIME:`)

### ตัวอย่างค่าที่ถูกเติมลงช่อง

```
CH01 = 30
CH02 = 100
CH03 = 200
TURN ON  = 0.50 s
TURN OFF = 3.00 s
```

---

## 🔷 6. Live Status (ส่วน 01)

หลัง connect โปรแกรมจะ poll ค่าจากบอร์ดทุก ~1 วินาที (คำสั่ง `GETALL` → `ALL:`) และแสดง:

* **S1 / S2 / S3** — ค่าระยะที่ sensor วัดได้จริง (cm) ถ้าเป็น 0 จะแสดง `--`
* **RELAY** — สถานะเอาต์พุต:
  * `ON` = pill เขียว
  * `OFF` = pill เทา
* จุด **LIVE** จะกระพริบเขียวสลับ แสดงว่ามีข้อมูลไหลเข้าจริง

---

## 🔷 7. การตั้งค่า Limit + Timing (ส่วน 02 / 03)

### ขั้นตอน

1. กรอกค่า Limit ที่ต้องการ (หน่วย cm):
   * CH01 (Sensor 1)
   * CH02 (Sensor 2)
   * CH03 (Sensor 3)
2. กรอกค่าเวลา (หน่วยวินาที):
   * **TURN ON** — เวลาหน่วงก่อนสั่ง Relay ON
   * **TURN OFF** — เวลาหน่วงก่อนสั่ง Relay OFF
3. กดปุ่ม:

   ```
   ▶  WRITE CONFIGURATION
   ```
4. รอข้อความบนปุ่ม:

   ```
   ✓  WRITTEN — CH: 30/100/200cm   T: 0.5/3.0s
   ```

> หมายเหตุ: ค่า RECHECK ถูกตั้งคงที่ภายในโปรแกรม (500 ms) และไม่แสดงบน UI

## 🔷 8. กฎของค่าที่ใส่ได้

**Limit (CH01 / CH02 / CH03):**

* ต้องเป็น **จำนวนเต็ม**
* ต้อง **มากกว่า 0**

**Timing (TURN ON / TURN OFF):**

* เป็นวินาที (ใส่ทศนิยมได้ เช่น `0.5`)
* อยู่ในช่วง **0.05 – 600 วินาที** (50 – 600,000 ms)

หากค่าผิดกฎ ปุ่มจะขึ้น `✕  ENTER VALID VALUES` และไม่ส่งค่า

## 🔷 9. การแสดงผล (Layout)

### ด้านบน (Header)

* ชื่อระบบ `SENSOR CONTROL UNIT · SCU-3 · v1.3.0`
* นาฬิกา (เวลา + วันที่) และ badge `SCU-3`

### ตรงกลาง (เลื่อนได้)

* `00 · COMMUNICATION` — เลือกพอร์ต / SCAN / สถานะ
* `01 · LIVE STATUS` — S1/S2/S3 + Relay
* `02 · SENSOR PARAMETERS (cm)` — 3 การ์ด CH01–CH03
* `03 · TIMING (seconds)` — 2 การ์ด TURN ON / TURN OFF

### ด้านล่าง

* ปุ่ม `WRITE CONFIGURATION` (ปักตรึงไว้เสมอ)
* แถบสถานะ เช่น `CONNECTED · COM7 · 9600 BAUD`

> หน้าต่างปรับขนาด / ขยายเต็มจอได้ ขนาดเล็กสุด 760×540 (เลื่อนดูส่วนที่เกินได้)

## 🔷 10. กรณีผิดพลาด

### ❌ ไม่มี COM port

* กดปุ่ม **SCAN**
* ตรวจสอบสาย USB

### ❌ Connect ไม่ได้ (CONNECTION FAILED)

* ตรวจสอบ driver USB-to-Serial
* ตรวจสอบว่าเลือก COM port ถูกต้อง
* พอร์ตอาจถูกโปรแกรมอื่นเปิดค้างอยู่

### ❌ ค่า Limit ขึ้นเป็น 0,0,0

* บอร์ดอาจไม่ตอบกลับคำสั่ง `GET`
* ตรวจสอบ firmware ว่าตอบ `LIMIT:` ถูก format
* ลองเสียบใหม่แล้ว connect อีกครั้ง

### ❌ Live (S1/S2/S3) ขึ้น `--` ตลอด

* บอร์ดไม่ตอบคำสั่ง `GETALL` หรือ format `ALL:` ไม่ถูก
* ค่าที่วัดได้เป็น 0 จริง (ไม่มีวัตถุในระยะ)

### ❌ Write ไม่สำเร็จ (WRITE FAILED)

* ตรวจสอบว่า connect อยู่หรือไม่
* ตรวจสอบค่าที่ใส่ให้อยู่ในกฎ (ข้อ 8)

## 🔷 13. Serial Protocol (สำหรับนักพัฒนา / Firmware)

Baud rate: **9600**, รูปแบบบรรทัดลงท้ายด้วย `\n`

| ทิศทาง        | คำสั่งที่ส่ง            | คำตอบที่คาดหวัง                          |
| ------------- | ---------------------- | ---------------------------------------- |
| อ่าน limit    | `GET`                  | `LIMIT:<l1>,<l2>,<l3>`                    |
| อ่าน timing   | `GETTIME`              | `TIME:<t1>,<t2>,<t3>` (ms)                |
| อ่านสถานะรวม  | `GETALL`               | `ALL:<s1>,<s2>,<s3>,<relay>,<current>`   |
| เขียน limit   | `<l1>,<l2>,<l3>`       | —                                        |
| เขียน timing  | `TIME:<t1>,<t2>,<t3>`  | — (ms)                                   |

* `relay` : `1` = ON, `0` = OFF
* `current` : เลขทศนิยม (float)
* `t1`=TURN ON, `t2`=TURN OFF, `t3`=RECHECK (ms)

## 🔷 14. FAQ

### Q: ทำไมเปิดโปรแกรมแล้วไม่เห็น COM?

A: อาจยังไม่ได้เสียบอุปกรณ์ หรือสาย USB ไม่เสถียร — กด **SCAN** อีกครั้ง

### Q: ทำไมค่า Limit เป็น 0,0,0?

A: ยังไม่ได้ connect, connect ผิด COM Port หรือบอร์ดไม่ตอบคำสั่ง `GET`

### Q: ทำไม S1/S2/S3 เป็น `--`?

A: ค่าที่บอร์ดส่งเป็น 0 (ไม่มีวัตถุในระยะ) หรือบอร์ดไม่ตอบ `GETALL`

### Q: ใช้กับ Mac ได้ไหม?

A: ไม่ได้ — Software v3 (v1.3.0) รองรับเฉพาะระบบปฏิบัติการ Windows
