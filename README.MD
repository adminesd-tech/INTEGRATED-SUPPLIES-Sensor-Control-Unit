# 🔧 SENSOR CONTROL UNIT (SCU)

ระบบตั้งค่าและควบคุม Sensor สำหรับการใช้งานจริงในหน้างาน

> เวอร์ชันล่าสุด: **Version3 — SCU-3 (v1.3.0)**

---

## 📌 Overview

SCU ใช้สำหรับ:

* ตั้งค่าระยะตรวจจับของ Sensor
* ตั้งค่าเวลา (Timing) การทำงานของ Relay
* ควบคุมการทำงานของระบบ Output (Relay)
* ตรวจสอบสถานะการทำงานแบบ real-time

## 🚀 เริ่มต้นใช้งาน (Version3)

1. เข้าไปที่:

```
Version3/
```

2. เปิด:

```
SCU3.exe
```

3. เสียบอุปกรณ์เข้าคอมพิวเตอร์

4. ระบบจะ **SCAN พอร์ตอัตโนมัติ** (หรือเลือก COM Port เองได้)

5. ระบบจะเชื่อมต่อและดึงค่าจากบอร์ดอัตโนมัติ

---

## ⚙️ วิธีใช้งาน

### 📥 อ่านค่า (อัตโนมัติ)

* เมื่อเชื่อมต่อสำเร็จ ระบบจะดึงค่า Limit และ Timing จากบอร์ดมาแสดงทันที
* ค่า Live (S1/S2/S3) และสถานะ Relay จะอัปเดตแบบ real-time

---

### 📤 ตั้งค่าใหม่

1. ใส่ค่า Limit: **CH01 / CH02 / CH03** (หน่วย cm)
2. ใส่ค่าเวลา: **TURN ON / TURN OFF** (หน่วยวินาที)
3. กด:

```
WRITE CONFIGURATION
```

---

## 💡 การแสดงสถานะ Sensor (สำคัญ)

ส่วน **LIVE STATUS** แสดงค่าระยะที่ Sensor วัดได้จริง และสถานะ Relay:

| การแสดงผล             | ความหมาย                       |
| --------------------- | ------------------------------ |
| S1 / S2 / S3 มีตัวเลข | Sensor วัดระยะได้ (มีวัตถุ)    |
| S1 / S2 / S3 = `--`   | ไม่มีวัตถุในระยะ (ค่าเป็น 0)   |
| RELAY 🟢 ON           | ระบบสั่ง Output ทำงาน          |
| RELAY ⚫ OFF           | ระบบ Output หยุดทำงาน          |

👉 ใช้ดูได้ทันทีว่า Sensor และ Relay กำลังทำงานอยู่หรือไม่

---

## 📊 ความหมายของค่า

| ค่า     | ความหมาย                          |
| ------- | --------------------------------- |
| CH01    | ระยะตรวจจับ Sensor ตัวที่ 1 (cm)  |
| CH02    | ระยะตรวจจับ Sensor ตัวที่ 2 (cm)  |
| CH03    | ระยะตรวจจับ Sensor ตัวที่ 3 (cm)  |
| TURN ON | เวลาหน่วงก่อนสั่ง Relay ON (วินาที) |
| TURN OFF| เวลาหน่วงก่อนสั่ง Relay OFF (วินาที) |

---

## 🔁 สถานะระบบ

| สถานะ     | ความหมาย           |
| --------- | ------------------ |
| CONNECTED | เชื่อมต่อสำเร็จ    |
| OFFLINE   | ยังไม่เชื่อมต่อ    |
| FAILED    | เชื่อมต่อไม่สำเร็จ |

---

## ❗ การแก้ปัญหาเบื้องต้น

### ไม่พบ COM

* กด SCAN
* เช็คสาย USB

---

### Sensor ไม่ขึ้นค่า (S1/S2/S3 = `--`)

* ตรวจสอบว่ามีวัตถุอยู่ในระยะหรือไม่
* ตรวจสอบการเชื่อมต่ออุปกรณ์ / firmware

---

### ค่า Limit เป็น 0,0,0

* ยังไม่ connect
* หรืออุปกรณ์ไม่ตอบกลับ
